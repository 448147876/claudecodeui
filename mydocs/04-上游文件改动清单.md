## 2. 已审核的路径参数（静态扫描白名单）

检查脚本（`03-技术方案.md` 第 11 节第 5 步）在上游 `server/` 中扫描客户端可控的路径类表达式，与本表比对。比对键为「文件 + 表达式」。**本表之外出现的新表达式会让检查失败**，需要人工审核后补进本表。

扫描规则：

```
\b(req|request|body|data|message|msg|payload|options|clientOptions|context|input|params|query)\??\.[A-Za-z]*(path|Path|cwd|Cwd|dir|Dir|root|Root)\b
```

结论说明：**补丁 #n** = 由第 1 节的改动覆盖；**上游已校验** = 上游已经用 `WORKSPACES_ROOT` 或项目根目录做了限制；**库内查找** = 路径来自本账号数据库，不是客户端；**内部** = 不是 HTTP / WS 入口，参数来自服务端自己；**接受** = 按需求不做隔离。
